### Create a Cloud Gateway Admin portal

The Admin Portal should be able to list down all the routes and the health status of the routes.

The Admin portal should also be able to add , delete and update the routes in the cloud gateway dynamically without restarting the gateway server.

This portal should be a SPA, using Vue.js and should be accessible via a dedicated URL protected by OAuth2 and should be accessible only by Admin Users.

Introduce the Auditing feature in the Admin Portal.

The portal should be able to show when the route was create, updated and deleted by whom and when. also giving the version number of the route.
